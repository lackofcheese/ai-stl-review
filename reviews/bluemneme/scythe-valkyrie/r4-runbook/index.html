Goal

Choose a safe editing mechanism before attempting the remaining wallpaper repairs. Every paid arm makes the same W1 change: remove the third lower-left wing while preserving the correct upper wing and every pixel outside the smallest declared edit surface.

The earlier twelve-choice proposal tried to finish both wallpapers while also testing three mechanisms and two models. Four review rounds found 33 issues, 15 blocking. The last gate found that the W1 wing and blade rectangles overlap by 620×270 pixels, so the second paste could silently undo the first. It also found native-extension assumptions and missing composite lineage records. This amendment removes the interacting edits instead of adding another safeguard.

SCYTHE VALKYRIE R4 — ONE-EDIT COMPARISON BRIEF

Compare each candidate only with the untouched W1 control. The one requested
content change is complete removal of the separate third lower-left wing: the
wing mass rooted lower on her back and sweeping down and toward the VIEWER'S
LEFT. Every feather, spar and hub belonging to that lower wing must be gone,
and the smoky red-brown haze, ruins and cloth behind it must be restored
convincingly.

The correct upper wings must remain: the same armoured hubs, jointed mechanical
segments, feathers, pose and silhouette. The finished figure has exactly two
wings and no replacement wing, limb, feather or new object.

Apart from that removal, preserve the W1 control's woman, face, expression,
hair, halo crown, armour, ornament, pose, scythe and blade, hands, background,
lighting, colour grading, texture, tall framing and composition. The scythe is
deliberately unchanged in R4; do not grade it against a future blade target.

Mark the requested edit bad if the lower wing remains, the background fill is
visibly broken, a retained upper wing is damaged, anatomy or an existing object
is broken, or a new object appears. Report other unrequested changes neutrally
and describe their location and extent; the human reviewers decide whether
they are improvements. Do not grade the deferred mechanism catalog as part of
this round.

How the round is judged

R4 chooses a mechanism, not a finished wallpaper. Jake's and Dimitri's eyes decide whether the removal/fill looks good; machine evidence establishes what changed and whether the files are safe to compare.

  • Judge every candidate against the untouched W1 control. Report unrequested changes neutrally; mark bad only a failed requested edit, broken anatomy, a damaged retained upper wing, or an invalid composite.
  • FAST (free): every returned image must decode and preserve the expected crop or full-frame aspect. region_edit.py must verify from the written PNG that each composite changes zero pixels outside its declared rectangle. edit_diff.py records pixel, perceptual, silhouette, and regional measures. A fresh-context crop audit compares the unwanted lower wing, the retained upper wing, the feather boundary, the face, hands, scythe, and background against the control. Once all six FAST records exist, publish a clearly labelled PROVISIONAL — slow checks pending review panel.
  • SLOW (paid): one blind_detect_round.py manifest covers the six full-frame candidates in two Batch waves. Its comparison brief is the round's one-edit contract, not the whole character spec: the unchanged blade is deliberately outside R4. Append its records, reconcile any disagreement with the crop audit, then refresh the same panel as COMPLETE.
  • The human decision is one of: adopt surgical whole-picture editing, adopt steered regeneration, adopt crop and paste-back, record a tie for a later deciding round, or reject all three. No R4 result is called a finished wallpaper and no blade/W2 work starts until the complete panel has a recorded human verdict.

set -euo pipefail

native_roll() { # native_roll <stem> <roll>
  local stem="$1" roll="$2"
  local hits=()
  mapfile -t hits < <(find "$G" -maxdepth 1 -type f \
    \( -name "$stem-$roll.png" -o -name "$stem-$roll.jpg" \
       -o -name "$stem-$roll.jpeg" -o -name "$stem-$roll.webp" \) -print)
  (( ${#hits[@]} == 1 )) || {
    echo "$stem-$roll: expected one native image, found ${#hits[@]}" >&2
    return 1
  }
  printf '%s\n' "${hits[0]}"
}
append_composite() { # id out raw prompt note
  "$PY" - "$T/lineage.json" "$1" "$2" "$3" "$W1" "$4" "$5" <<'PY'
import datetime, pathlib, sys
from tools.genlog import append_lineage_record
lineage, artifact_id, out, raw, base, prompt, note = sys.argv[1:]
append_lineage_record(pathlib.Path(lineage), {
    "id": artifact_id,
    "kind": "derived-composite",
    "files": [out],
    "input_images": [raw, base],
    "prompt_file": prompt,
    "notes": note,
    "generated": datetime.datetime.now().isoformat(timespec="seconds"),
}, unique_by=("id",))
PY
}
for n in 1 2; do
